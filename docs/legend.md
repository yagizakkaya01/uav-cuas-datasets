---

| Badge | Meaning | Practical Implication |
|:---:|---|---|
| 🟢 **Open** | Freely downloadable, no registration, no signed agreement | Use immediately, cite the source |
| 🟡 **Open + Conditional** | Accessible, but the license carries a condition | Check the specific condition before redistribution (see table below) |
| 🔴 **Gated** | Requires registration, institutional approval, or a signed Data Use Agreement | Budget lead time — some approvals take days to weeks |
| ⚫ **Unverified** | Referenced in secondary literature but no locatable, accessible primary source | **Do not build on this** — flag and move on |
| ✅ **Personally Verified** | A team member has actually accessed / downloaded this specific resource | Highest-confidence entries — cite with "personally verified [date]" |

## Common License Conditions in This Repo

| License | What it means for us |
|---|---|
| **MIT** | Free for any use, including commercial, with attribution. No risk for academic work. |
| **CC BY 4.0** | Free to use, must attribute the original creator. |
| **CC BY-NC-SA 4.0** | Free for **non-commercial** use only; derivative work must carry the same license. Fine for a thesis; do not use in anything sold or licensed commercially. |
| **CC0 1.0** | Public domain equivalent — no restrictions at all. |
| **ODbL (OpenStreetMap)** | "Share-alike": if you publicly redistribute a derived database, it must carry the same license. Using it internally for a thesis project is not a problem. |
| **Copernicus free license** | Free to use, but requires the specific attribution string: *"© DLR e.V. [year] and © Airbus Defence and Space GmbH [year] provided under COPERNICUS by the European Union and ESA."* |
| **Academic-only (OpenSky)** | Free for research/academic use; commercial use requires a separate paid license. |

## A Note on "Real but Restricted" vs. "Fabricated"

A source being gated (🔴) or conditionally licensed (🟡) does **not** make it synthetic or invalid — it simply means access has a process. This distinction matters when presenting the methodology: a dataset requiring a Data Use Agreement (e.g. Drone-vs-Bird) is still real, peer-reviewed, evidence-based data — the opposite of an arbitrary assumption. The only category that should never be cited as evidence is ⚫ **Unverified**.
